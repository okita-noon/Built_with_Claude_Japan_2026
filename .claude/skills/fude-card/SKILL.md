# 筆カードと聞き直し

スキーマ：`evals/schema/fude-card.schema.json`

## 筆カードの作り方

- 親の言葉は `shogen` にそのまま残す。要約で上書きしない。
- 各項目に出どころ（`evidence.source`）を付ける：親の証言／課税明細書／登記／公開地図／航空写真／家族／不明。
- 「覚えていない」「ようわからん」は `不明` として正式に記録し、責めない。
- 課税明細書の地目は現況課税のことがある。登記の地目と食い違えば `F_CHIMOKU_MISMATCH`。
- 任意座標系で地図に置けない筆は「位置未確定」とし、カードだけ作る。

## 呼び名 → 地番

1. 呼び名（例：沢の上の田んぼ）を1つの単位として記録し、あとで複数の地番に紐付ける。
2. 候補は「課税明細書・名寄帳にある自家の筆」に限定してから、地図上の位置・形・地目で絞る。
3. 決めきれないときは、候補に番号を振った地図画像を作り、「道沿いの細長いほう？奥の四角いほう？」の二択で聞く。
4. 最後は家族がタップで確定する。AI だけで確定しない。

## 聞き直し質問の型

- 一度に一問。はい／いいえ か 二択で答えられる形。
- 親の言葉と地名を使う：「沢の上の田んぼのとこに、物置はあった？」
- 責める・急かす・死後を連想させる言葉を使わない（相続、処分、国に返す、申請、期限）。
- 入口は思い出から：「お父さんはそこで何を作ってた？」
- 1回の通話は1〜2か所まで。疲れのスコアが高ければ、続きは次回にする。

## 1回の通話の充足率

必須項目（building, boundary, others_use, rights, forest_care または農地の利用状況, shogen）のうち、`不明` 以外で埋まった割合。通話の前後で記録し、`docs/eval-log.md` に残す。
