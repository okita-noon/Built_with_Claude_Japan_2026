# デザインシステム

## 1. レイアウトで説明する（補助ラベルを足さない）

意味は「どこに置くか」「どれだけ大きいか」「何と並ぶか」で伝える。説明文・キャプション・小さな注記・バッジを足して補わない。

- 1つの要素に見出しは1つ。見出しの下にサブタイトルや補足文を付けない。
- 状態はテキストのタグではなく**位置**で示す。例：判定は4本のレーン（申請不可／不承認の可能性が高い／情報が足りない／検討できる）を横に並べ、筆カードがどのレーンに入るかで伝える。レーン名は上端に1回だけ。
- 進み具合は文字ではなく**量**で示す。例：カードの必須項目は小さなマスの列で、埋まったマスが塗られていく。
- 単位や出典は表の見出しかカードの裏面へ。本文に繰り返さない。
- 補助ラベルを足したくなったら、まず並び順・余白・大きさ・グルーピングで解けないか試す。足すときは理由を PR に書く。
- 例外：法的な注意（「参考情報」「最終判断は法務局」）は省略しない。ただし文ではなく、カードの縁の色と位置で一貫して示し、文言は1か所にまとめる。

## 2. 画面ごとの性格

| 画面 | 性格 | 動きの量 |
| --- | --- | --- |
| 親の画面 | 静か・大きい・一度に一つ | 最小。ゆっくり、点滅なし |
| 家族の画面 | 地図とカードが生きて動く | 多い。デモの見せ場 |
| 窓口の画面 | 表とCSV。仕事道具 | 控えめ。行の出入りだけ |

親の画面：文字は本文24px以上、ボタンは高さ88px以上。画面に置くのは「いま話している場所の写真1枚」と「話すボタン」だけ。

## 3. アニメーション仕様（Motion＋View Transitions）

トークン

| 名前 | 値 | 用途 |
| --- | --- | --- |
| `--ease-out` | cubic-bezier(0.22, 1, 0.36, 1) | 現れる |
| `--ease-in-out` | cubic-bezier(0.65, 0, 0.35, 1) | 移動 |
| spring.soft | stiffness 170, damping 26 | カード・レーン移動 |
| spring.pop | stiffness 400, damping 22 | マスが埋まる |
| dur.short / base / long | 160 / 320 / 640 ms | — |

場面ごとの動き

1. **筆が色づく**：会話で筆が特定されたら、地図上のポリゴンを中心から外へ塗る（long、ease-out）。未確定の候補は輪郭だけが呼吸するように明滅（2.4秒周期、不透明度0.4↔0.8）。
2. **地図からカードが立ち上がる**：筆をタップすると、ポリゴンの形からカードへ共有要素トランジション（View Transitions、base）。
3. **聞き直しの山場**：要件が足りないマスが1つずつ揺れ（x方向±3px、2回）、二択の質問カードが下からせり上がる（spring.soft）。親が答えるとマスが spring.pop で埋まり、カードがレーン間を滑って移る（spring.soft）。
4. **声の可視化**：親が話している間、話すボタンの周りの輪がゆっくり膨らむ（音量に追従、上限1.15倍）。AI が考えている間は輪が細く回る。
5. **ガードの言い換え**：断定表現に取り消し線が引かれ（short）、言い換え文がその場でクロスフェード（base）。デモ用に再生速度を0.5倍にできるデバッグ切替を用意。
6. **家族の意向がそろう**：各自のカードが重なり、一致した筆だけが前面に集まる（spring.soft、stagger 40ms）。割れた筆は「保留」の列へ静かに下がる。
7. **窓口の一覧**：行が上から順に現れる（stagger 20ms、short）。CSV 書き出しで行が一瞬ハイライト。
8. **数字の変化**：評価スコアや充足率はカウントアップ（long）。前の値を薄く残して差を見せる。

守ること

- `prefers-reduced-motion: reduce` では移動・拡大を止め、不透明度の変化だけにする。親の画面は既定でこのモード。
- 1画面で同時に動く主役は1つ。ほかは静止か不透明度のみ。
- 動きは意味の変化（特定・不足・充足・移動）にだけ付ける。飾りのループを置かない。
- 60fps を保つ。transform と opacity 以外をアニメーションしない。地図はレイヤーの paint プロパティで。
