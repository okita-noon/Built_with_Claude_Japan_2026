# 制度チェック

出典：法務省 [引き取ることができない土地の要件](https://www.moj.go.jp/MINJI/minji05_00461.html)、[制度の概要](https://www.moj.go.jp/MINJI/minji05_00457.html)、[Q&A](https://www.moj.go.jp/MINJI/minji05_00459.html)。コード表は `evals/README.md`。

## 出力（tool use で強制）

```json
{"verdict":"…","reasons":["R_…"],"asks":["Q_…"],"deadlines":[{"code":"DL_TOUKI","date":"YYYY-MM-DD"}],
 "flags":["F_…"],"text":"家族向けの説明","citations":["法令名と条・資料URL"]}
```

## 判定の順序

1. 申請資格：売買など相続等以外で取得 → `E_NOT_INHERITED`（申請不可）。共有 → `E_COOWNERS_ALL`（全員での申請が必要）。共有として扱うのは、名義欄に「共有」とあるとき、取得欄に「遺産分割していない」「未確定」とあるとき、名義が祖父母など被相続人より前の代のままのときだけ。名義が被相続人（父・母）のままで取得が「相続」なら、共有として扱わない。共有のときは、共有者全員（亡くなった共有者はその相続人）がそろって申請できると確認できるまで「判断に必要な情報が足りない」とし `Q_HEIRS` を出す。相続登記が未了でも、相続で取得していれば申請はできる（Q&A 6-3）。
2. 却下事由 `R_*` が1つでもあれば「申請不可」。
3. なければ不承認事由 `D_*` が1つでもあれば「不承認の可能性が高い」。
4. なければ、判断に必要な項目に「不明」や「親の証言のみ」が残っていれば「判断に必要な情報が足りない」とし、対応する `Q_*` を出す。
5. すべてそろって問題がなければ「要件上は検討できる」。

## 細かい線引き

- 未登記でも、屋根と周壁があり土地に定着した小屋・倉庫は建物（`R_BUILDING`）。簡易な物置は建物に当たらない場合があり、その場合は地上の有体物（`D_SURFACE_OBJECT`）として扱う（Q&A 7-5）。造りが不明なら `Q_BUILDING`。
- 口約束の耕作や貸し借りは使用収益権（`R_SECURITY_USE`）。完済済みでも抹消していない抵当権は残っている扱い。
- `R_OTHERS_USE`（施行令2条）：**墓地内の土地と境内地は、利用の有無を問わず該当**（先祖の墓だけの墓地も含む）。通路・水道用地・用悪水路・ため池は「現に利用されている」ときだけ該当し、使われていなければ該当しない（Q&A 6-12）。墓石は建物でも地上の有体物でもなく、墓地として `R_OTHERS_USE` で扱う。
- 境界：「隣と争いがある」は `R_BOUNDARY_DISPUTE`。「親の証言のみ」は却下と決めつけず、`Q_BOUNDARY`（現地で示せるか、隣と争いがないか）を聞く。
- 竹や倒れそうな枯れ木は `D_SURFACE_OBJECT`。手入れされていない人工林は `D_FOREST`。
- 毎年の土地改良区賦課金は `D_MONETARY_DEBT`。
- 登記の地目と現況が違えば `F_CHIMOKU_MISMATCH`（例：登記は畑、現況は竹林）。

## 期限

- `DL_TOUKI` 相続登記：相続を知った日から3年。2024-04-01より前の相続は2027-03-31まで。名義が被相続人のままのときに出す。
- `DL_NOUCHI_TODOKE` 農地を相続で取得 → 農業委員会へ届出（おおむね10か月）。過ぎていそうなら「速やかに」。
- `DL_SHINRIN_TODOKE` 地域森林計画の対象森林の所有者になった → 市町村へ届出（90日）。

## 書き方

- 結論は「可能性」と「足りない情報」で書く。「承認されます」「引き取ってもらえます」は禁止。最終判断は法務局と必ず添える。
- 費用は事実だけ：審査手数料は1筆14,000円（返還なし）、負担金は原則20万円（森林や市街化区域の宅地・農地などは面積で算定）。
- 国庫帰属だけを勧めない。「残す／託す（農地バンク・森林経営管理制度）／譲る／保留」と並べる。
