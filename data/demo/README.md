# 和歌山架空集落「大字 栗原」（くりはら）

デモ用のつくりばなし。実在の地名・地番・座標とは関係ない。実在家族の実データは絶対に置かない。

- 位置：和歌山県田辺市の山あいを想定（地図の位置は空中写真に合わせて置いただけで、実在の地番・所有とは関係ない）
- 筆：10筆（畑3・田2・山林4・宅地1）
- 親の呼び名：方言混じりの短い言葉。地番は家族の画面側で紐付け
- 位置未確定の筆：D002（任意座標系で地図に載せられない）、D010（口伝えだけ）

ファイル:

- `fude.json`：筆カード10件
- `fude.geojson`：地図に置けるポリゴン（公共座標系の筆のみ）
- `shogen.json`：親の証言サンプル（デモの会話で使う）
- `tax-slip.json`：課税明細書のモック OCR 結果（画像のかわり）
