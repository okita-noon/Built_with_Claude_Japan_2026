# 進捗（2026-11-04 深夜）

CLAUDE.md の作業手順1〜4までを、API 全モックで通した。朝のレビュー用。

## 決めたこと（この夜に）

- **フォント**：ブランドと見出しに **Yuji Boku**（Google Fonts の筆書体）、本文に Noto Sans JP、サブ見出しに Shippori Mincho。地目などのアイコンは**漢字一文字を筆フォントで**（畑／田／山／宅／森／農／司／期／持／参）。SVG 線のアイコンはチェック・バツ・問いの3つだけ（`BrushGlyph.tsx`）。
- **デザイン**：補助ラベルを置かず、意味は**位置と大きさ**で持たせる（判定レーン4本・筆カードのマス列・窓口切替タブ）。
- **モック戦略**：Vertex AI の Claude は接続せず、`src/lib/judge.ts`・`guard.ts` にルールを置いて、UI と評価の両方で共有。評価の `--mock` フラグで同じコードから予測を出す。
- **データ**：和歌山想定の架空集落「大字 栗原」。筆10件、位置が確定した8件は `fude.geojson` にポリゴン。実在の地番・座標ではない。

## 動いているもの

- `/` 子のオンボーディング：町名入力 → 課税明細書のモック撮影 → 筆が1つずつ現れる
- `/family` 家族の画面：期限バー、地図（MapLibre、判定で色づけ）、判定レーン4本、筆カード（必須10マス・親の証言・判定文・聞き直し二択）
- `/parent` 親の画面：写真1枚、巨大な話すボタン、二択の質問1問だけ
- `/counter` 窓口の画面：林務／農業委員会／司法書士の切替、相談持参物、CSV ダウンロード

API（Route Handler・すべてモック）

- `GET /api/demo` 筆・GeoJSON・証言・OCR
- `POST /api/judge` 筆カード → 判定
- `POST /api/next-question` 筆カード → 次の二択
- `POST /api/guard` 入力案（prompt or output）→ ガード決定
- `POST /api/ocr` 課税明細書のモック

## 既知の課題（朝イチで触りそうなもの）

1. **判定ルールが浅い**：地下埋設（`D_UNDERGROUND_OBJECT`）、袋地（`D_NEIGHBOR_LITIGATION`）、資格（`E_NOT_INHERITED`・`E_COOWNERS_ALL`）を見ていない。seido eval の失敗6件のうち4件がこの筋。
2. **MapView の見た目**：空中写真タイルがまだ無く、ポリゴンがグレー地に浮いているだけ。地理院タイル or 自前の空中写真 PMTiles を入れる（`.claude/agents/map-data` の仕事）。
3. **親の画面の写真**：いまは SVG のダミー山景色。公開可能なフリー写真 or Gemini 画像生成を要検討。
4. **デモの会話録再生**：Gemini Live と Jev の連携はまだ入れていない。手順5。
5. **家族の論点表**：各自の意向を非公開で預かる仕組みは未着手。手順7。
6. **窓口の画面**：持参物リストはあるが、「相談への申込（Email雛形）」などは未着手。
