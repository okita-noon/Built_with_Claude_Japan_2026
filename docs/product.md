# 画面と体験

デザインのルールは `.claude/skills/design-system/SKILL.md`。ここでは何を置くかだけを書く。

## 0. はじめの5分（子が一人で）

1. 町名を入れる → 地図がその町へ寄っていく
2. 課税明細書か名寄帳を撮る → 筆が地図に1つずつ灯り、置けない筆（位置未確定）は画面の端に並ぶ
3. 「まず親に聞きたい場所」を1つ選ぶ
4. 親に電話をつなぐ → 親の画面へ

## 1. 親の画面

- 置くもの：いま話している場所の写真1枚、話すボタン
- 流れ：子が読み上げる質問（例：そこで何を作ってた？）→ 親が話す → ボタンの輪が声に合わせて膨らむ
- 聞き直しは一度に一問、二択
- 疲れのスコアが高くなったら「今日はここまで」と大きく出して終わる
- 出さない言葉：相続、処分、国に返す、申請、期限

## 2. 家族の画面

上から順に：

1. **地図**：空中写真、筆（公共座標系のみ）、山は林班・小班。話している筆は色づく
2. **判定レーン**：4本を横並び。筆カードがレーンに入り、聞き直しで埋まると隣のレーンへ移る
3. **筆カード**：親の言葉、必須項目のマス（埋まると塗られる）、出どころ、地目ずれ
4. **家族の論点**：各自が非公開で「残す／託す／譲る／国に返す／保留」を選ぶ → 全員がそろうと一致した筆だけ前に出る。割れた筆は保留の列へ
5. **期限**：相続登記（2027-03-31 など）を一番上に。届出の期限は対象の筆だけ

## 3. 窓口の画面（林務担当・農業委員会・司法書士）

- 窓口を選ぶと、その窓口に要る列だけの一覧になる
  - 林務・森林組合：林小班、地番、樹種・林齢（公開データ）、親の証言（施業・境界の手がかり）、家族の意向、連絡のつく相続人
  - 農業委員会：地番、現況、耕作者、地目ずれ、家族の意向
  - 司法書士：地番、名義、相続関係の概略、期限
- CSV 書き出しと「相談に持っていくものリスト」
- 法定様式の記入はしない

## 解かないこと（画面にも README にも書く）

山の値段、担い手不足、境界の確定。アプリが渡すのは、判断と相談のための材料。
